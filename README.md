# 🧠 DSA with Java

> My journey learning **Data Structures & Algorithms with Java**, one concept at a time.

This repository documents my progress while learning **Data Structures & Algorithms (DSA)** through **Kunal Kushwaha's DSA playlist**.

The goal isn't just to collect notes or copy solutions. It's to **understand the concepts, implement them from scratch, apply them, and gradually become better at solving problems.**

---

## 🎯 What This Repository Contains

* 📚 **Study Notes** — Clean notes covering the concepts taught in each lesson
* 💻 **Java Implementations** — Algorithms and data structures implemented while learning
* 📝 **Assignments** — Small tasks to reinforce theoretical concepts
* 🛠️ **Mini-Projects** — Small projects built when the lesson involves enough practical coding
* 🧩 **LeetCode Problems** — Relevant problems selected from the concepts I've learned
* 📈 **Progress Tracking** — Documentation of my learning progress over time

---

## 🗺️ Learning Path

The repository follows the progression of the **Kunal Kushwaha DSA playlist** rather than trying to create a separate curriculum.

```text
Learn
  ↓

  ↓

  ↓
Apply
  ↓
Solve Problems
  ↓

```

The focus is on gradually building strong fundamentals before moving into more advanced data structures and algorithms.
